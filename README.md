One sentence pitching a ridiculous invention that fixes a tiny everyday annoyance: a vacuum cleaner that eats one sock a week as a service fee and leaves a handwritten receipt on the rug — the absurd machine itself explains where all the lost socks went.

## Run it

```sh
python3 main.py
```

Writes the pitch to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`). Python 3 standard library only; deterministic — the same 106 characters on every run. A built-in gate checks the competition rules before writing: UTF-8 text, 1–220 characters, exactly one sentence, naming both the invention and the annoyance it fixes.
